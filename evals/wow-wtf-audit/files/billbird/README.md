# Billbird

Billbird is invoicing for freelancers who bill by the hour.

## Who it is for

The target user is a solo freelancer with a few clients.

## Core job

Send a correct invoice to a client in a couple of minutes.

## Run it

Billbird needs Node 22 and has no dependencies to install.
Run `make dev`.
Then open http://localhost:4173.
Set the `PORT` environment variable to use a different port.
Data is kept in memory and resets when the server restarts.
