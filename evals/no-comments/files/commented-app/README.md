# commented-app

A map of public places.
The backend is NestJS and the frontend is Preact.

- `backend/` - REST API, tested with Jest and supertest.
- `frontend/` - Preact components, tested with Vitest.
- `e2e/` - Playwright tests, run on CI for each push.
- `docs/` - knowledge that the code cannot show.

Run tasks through the `Makefile`.
Issues are tracked in Jira, project key `PROJ`.
Errors go to Sentry.
